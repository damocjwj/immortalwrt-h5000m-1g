# 旧版 TurboACC LuCI 页面视觉基线

记录时间：2026-07-17

参考对象：未精简前设备的“网络 → 网络加速”页面截图（2048 × 1080）。本文件只记录界面信息架构、
LuCI/Argon 视觉语言和交互，不将截图中的运行策略视为 H5000M 的默认值。

## 定位

旧版不是 Bootstrap 默认浅色皮肤，而是 **Argon 深色主题中的原生 LuCI CBI 表单页面**：

- 左侧为 Argon 的固定深灰导航栏，顶部是 `ImmortalWrt` 标识；一级“网络”以紫色实底高亮并展开。
- 二级菜单使用普通文本列表；“网络加速”以紫色细下划线/强调色标识当前页，而不是另起一张仪表盘卡片。
- 内容区从左侧导航后开始铺满可用宽度，整体深灰/近黑背景，无渐变背景、玻璃效果或悬浮英雄卡片。
- 页面结构是 LuCI 标准的“标题 → 简介 → 运行状态区 → 单一配置表单 → 底部操作按钮”。

因此，后续界面应以 LuCI 的 `form.Map` / `form.NamedSection` / `taboption` 和主题已有的
`cbi-*` 样式为主，不注入页面级色板、圆角卡片系统、定制按钮、仪表盘或自绘进度条。

## 页面层级与视觉细节

### 标题和简介

- 顶部标题为“网络加速设置”，置于一个较深的横向标题条中，使用大号浅灰粗体文字。
- 标题下的简短说明为“开源流量分发引擎（快速转发或硬件 NAT）。”，使用较小的浅蓝灰文字。
- 标题、说明和下方内容之间使用 LuCI 默认的留白与细分隔，不使用概览大卡片。

### 运行状态区

运行状态位于一个普通深色 CBI 区块中，使用两列信息布局：左侧为标签，右侧为状态或统计值。

- 标签依次为“快速转发引擎”“全锥形 NAT”“TCP 拥塞控制算法”“PPE0 已绑定连接数”“PPE1 已绑定连接数”。
- 已生效的文字状态为绿色斜体/强调文字；示例中为 `MediaTek HNAT`、`Boardcom Fullcone`、`CUBIC`。
- PPE 行右侧使用主题原有的细长深灰进度条，容量文字居中显示，例如 `0 / 32768 (0%)`；没有独立卡片标题、图标或阴影。
- 该区块服务于快速观察，不应把配置值与实时值混在同一字段中。

注意：参考截图中实时状态显示 `Boardcom Fullcone`，而下方配置下拉框显示“禁用”。这仅记录为
旧版运行/配置可能不同步的现象；H5000M 的目标默认值仍是 TurboACC 和 firewall 的 Full-cone 均为 `0`。

### 配置表单

配置部分是一个没有独立营销标题的连续标准表单区，字段从上至下依次排列：

1. 快速转发引擎（下拉框，示例为 `MediaTek HNAT`）
2. 启用以太网 HNAT（复选框）
3. 启用以太网 IPv6 HNAT（复选框）
4. 启用 AP 模式（文本输入；说明提示修改 IP/无线桥接时的用途）
5. HNAT 连接速率绑定阈值（pps）（文本/数字输入，示例为 `30`）
6. HNAT PPE 数量（下拉框，示例为 `2`，并提示重启后生效）
7. 全锥形 NAT（下拉框，示例为“禁用”）
8. TCP 拥塞控制算法（下拉框，示例为 `cubic`）

字段排版应保留以下 LuCI CBI 特征：

- 标签在固定宽度的左列右对齐；控件和说明在右列左对齐。
- 下拉框、输入框为中等固定宽度的深色矩形，只有主题默认细边框与下拉箭头，不使用胶囊形、渐变描边或状态徽章。
- 每个字段的说明文字位于控件下方，字号小于标签，低对比度灰色；说明负责解释影响，而非展示大段宣传语。
- 复选框保持原生小尺寸；配置项间以较大的垂直留白和极细分隔线区分。
- 不使用自绘“主通路 / 体验优化 / HNAT 高级项”大按钮式标签；若保留标签页，应使用主题默认 CBI tab 样式，且“运行状态”保持首个标签。

### 底部操作

- 页面右下角使用 LuCI 原生 `cbi-page-actions`：紫色“保存并应用”（带下拉箭头）、橄榄绿色“保存”、橙色“复位”。
- 按钮高度、间距、颜色和 hover 行为全部继承当前 Argon 主题，不在应用内覆盖。
- 页面内容很长时，底部操作区保持标准 LuCI 行为，不添加应用私有的悬浮操作栏。

## 后续实现约束

- 功能必须完整保留：主加速引擎、Full-cone、TCP CCA、HNAT IPv4/IPv6、绑定阈值、PPE 状态及可用的 HNAT 高级项。
- 视觉目标是“旧版原生 CBI 信息密度与 Argon 主题一致”，不是恢复旧版的实际 Full-cone 或其他运行默认值。
- 所有颜色应由当前 LuCI 主题决定；页面 JavaScript 不应插入 `<style>`、`ta-*` 自定义 CSS 类、渐变、英雄区或仪表盘卡片。
- 运行状态可在页面加载/刷新时读取；如果需要自动刷新，应只更新标准 CBI 值，不能改变页面布局或增加私有视觉组件。
